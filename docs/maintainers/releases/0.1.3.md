# InkKit 0.1.3

Slash block commands and host-provided note suggestions share one suggestion pop-up.

- Offer block commands when `/` is typed on an empty line with `slashMenu`, off by default. Hosts can select built-in commands with `commands` and supply their own with `customCommands`. `SlashMenuOptions`, `SlashCommandName` and `SlashCommand` are exported.
- Offer matching note names after `[[` through the optional `WikiLinkAdapter.suggest(query, context)` method. Requests support cancellation; obsolete results are ignored. Selecting a suggestion inserts an escaped wiki link in one checked edit.
- Filter and choose suggestions with the keyboard or pointer in a shared, scrollable pop-up with combobox and listbox semantics.
- Customize suggestion text with the `suggestions*` and `slash*` labels and appearance with the `--inkkit-menu-*` tokens.

Compatibility review: 0.1.3 is additive pre-1.0 work, so the planned 0.1.3 version is appropriate. No existing API is removed or renamed, and existing calls require no migration. The slash menu remains disabled unless a host enables it. Hosts without `WikiLinkAdapter.suggest` retain their existing behavior. See the [API reference](../../api.md) for signatures, defaults and guards.

One editing behavior also changes: a thematic break newly written inside a list item, quote, callout or footnote is written as `___` so it reopens unambiguously. Authored rules keep their spelling unless an edit rewrites their block.
