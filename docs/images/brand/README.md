# Brand assets

Use the `-light` files on light backgrounds and the `-dark` files on dark backgrounds. The suffix describes the background, not the lettering.

- `mark`: standalone symbol on a transparent canvas; also used as the favicon.
- `wordmark`: Inkkit lettering on a transparent canvas.
- `logo`: symbol and wordmark together, cropped for a website header.
- `banner`: 3000 × 692 image with the approved description and an opaque background.

The palette is neutral: `#171717` ink, `#F5F5F5` light lettering, and `#FAFAFA` light banner background. The dark banner uses `#171717`. Do not add cream or blue accents.

These PNGs preserve the supplied artwork and its transparency. They are raster exports, not editable type or vector masters. Use the same file for each placement rather than redrawing the letters. The wordmark reads **Inkkit**; the package remains `@aicayzer/inkkit`.

## Documentation styling

Use the graphite palette for navigation, links and highlights: `#505050` on light backgrounds and `#D4D4D4` on dark backgrounds. Use neutral greys for supporting content. Keep Mintlify’s native corners, cards, spacing, typography and semantic callout colours; the palette preview is not a component specification. Warning and error colours convey meaning rather than branding.
