# Inkkit 0.7.4

This patch release lets a host give wiki links their look. A host that sets nothing sees no change.

**A wiki link can show an icon.** `WikiLinkAdapter.resolve` may return a new `WikiLinkPresentation` next to `missing`: an `icon`, drawn as a mask, an `iconColor`, and a `tint` for a host's look to fill the link with. It stays synchronous. The icon sits before the link's first character and stays with it when a line wraps. It is not in the link's accessible name, the Markdown source, the clipboard, print output or the saved bytes. A missing link draws no icon. An icon address that reaches the network or runs a script, and a value that is not one CSS color, are refused, and `file-unavailable` is reported. See [the adapters reference](https://inkkit.cyzr.me/reference/adapters).

**Every part of a wiki link's look is a token.** New tokens set its color, underline, hover, icon, background, padding and corners, each with today's look as its default. Set `--inkkit-wiki-link-icon-display` to `none` to hide icons. See [the appearance reference](https://inkkit.cyzr.me/reference/appearance).

Hosts update the package, rebuild their offline page and regenerate license notices. The unchanged `InkKitRTF` Swift package resolves from the same release tag.
