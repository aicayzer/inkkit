# Inkkit 0.7.0

This release moves the find bar, image refusal, link handling and history control that hosts were writing themselves into the editor. It raises the minor version because it adds public API and changes two behaviors.

**Find sessions.** `editor.findSession(onChange)` returns a `FindSession` that keeps a find bar's query and reports a `FindState` (`query`, `current`, `total` and the document version) whenever it changes. `find`, `next` and `previous` wrap at the ends, `replace` replaces one match and moves to the next, and `replaceAll`, `clear` and `close` complete the set. The session refreshes after edits, undo, selection and mode changes, and reloads; a reload keeps the query and a new load clears it. Hosts no longer need their own loop over `searchMatches`, `textSnapshot` and `selectTextRange`. See [Build your own find](https://inkkit.cyzr.me/guides/controls#build-your-own-find).

**Image input without an adapter is refused.** With no `images` adapter, a paste or drop that would insert an image now inserts nothing, not placeholder text, and `events.error` receives the new `image-unsupported` code (`paste` rejects with it). Hosts that mounted without an adapter and showed their own refusal can drop that code. With an adapter, behavior is unchanged. Content that only carries an image, such as a table kept as source, is not refused, and RTF documents refuse image bytes while still dropping the images of pasted HTML. See [images without an adapter](https://inkkit.cyzr.me/reference/adapters#images-without-an-adapter).

**Link addresses.** `CaretState.href` carries the address of the link at the caret, or the first link in a range, so a Link sheet can start from it. The new `normalizeLinkAddress(input)` prepares what a person types (a bare host gets `https://`, `host:port` is not a scheme, a colon ends a scheme only before `//` or after `mailto` and `tel`, and only http, https, mailto and tel are accepted), and `canOpenLink(address)` is the policy for opening one. See [link addresses](https://inkkit.cyzr.me/reference/editor#link-addresses).

**Discard an undone step.** `editor.discardUndone()` drops the steps that `undo` took off the history, for hosts that add content after an undo. It is not an edit and keeps the undo steps. See [discardUndone](https://inkkit.cyzr.me/reference/editor#discardundone).

**Migration: wiki-link backslashes.** A backslash inside a wiki link is now plain text, as in Marfa. `[[x\]]` is a link named `x\`, and `\[[escaped]]` is the link `escaped` after a literal backslash. `[`, `]`, `|` and `#` can no longer be escaped inside a link, so a `suggest` name that holds one is refused with `file-unavailable`, and `suggest` names are written as `[[name]]`. A document that used `\|`, `\#`, `\[`, `\]` or `\\` inside a wiki link reads those backslashes as text; check such notes. In a table cell `\|` is still the table's own pipe. File embeds (`![[name]]`) keep their escapes. Saved bytes are unchanged for unedited notes.

Hosts update the package, rebuild their offline page and regenerate license notices. The unchanged `InkKitRTF` Swift package resolves from the same release tag.
