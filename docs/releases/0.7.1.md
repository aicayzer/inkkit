# Inkkit 0.7.1

This patch release closes a gap in the image refusal added in 0.7.0.

**Source and TXT report refused images.** With no `images` adapter, a paste or drop that held only an image in the Markdown source or TXT surface inserted nothing and reported nothing. It now reports `image-unsupported` through `events.error`, as the formatted surface does, and `paste` rejects with it when the call holds only `images`. Text that comes with an image is inserted as before, and with an `images` adapter behavior is unchanged. A dropped image file is still left to the host when only a `files` adapter is set. See [images without an adapter](https://inkkit.cyzr.me/reference/adapters#images-without-an-adapter).
