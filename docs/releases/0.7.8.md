# Inkkit 0.7.8

This patch release adds a quiet look for a file that a host has not loaded yet. It is additive: a host that sets none of the new fields sees no change, and no existing field changes meaning.

**A `file` presentation can draw a placeholder.** `FilePresentation` with `kind: 'file'` takes three new optional fields:

- `appearance: 'placeholder'` draws one quiet line of text in place of a card: a small symbol, the label in secondary text and, when `action` is set, a button.
- `symbol` is `'image'` or `'file'` and picks the small picture drawn before the label. It defaults to `'image'`.
- `action` is the text of the button. The button calls `FileAdapter.open` for that reference alone. Without `action`, or without `FileAdapter.open`, the line has no button.

A placeholder copies and prints as `[File: label]`, like a card, and the button text never reaches that output. An unknown `appearance` or `symbol`, or an empty `action`, makes the presentation invalid. `symbol` and `action` have no effect without `appearance: 'placeholder'`, and `layout` and `activation` have none on a placeholder. A host swaps a placeholder for a picture or a card with `refreshReferences`, which redraws it in place and leaves the document's bytes unchanged.

See [the adapters reference](https://inkkit.cyzr.me/reference/adapters) and [the appearance reference](https://inkkit.cyzr.me/reference/appearance).

Hosts update the package and rebuild their offline page. The unchanged `InkKitRTF` Swift package resolves from the same release tag.
