# Inkkit 0.6.1

Hosts can call `searchMatches(text)` to obtain every match as a snapshot-scoped text range. The method uses the same literal, case-insensitive matching as Find and Replace All, so a native find bar can show accurate counts and navigate in either direction without taking focus from its search field. It changes neither the document nor selection, highlights or undo history.

Formatted search and replacement now exclude hidden author comments, matching the editor's readable-text projection. Search or replace in source mode to include comment bodies. Existing comments remain unchanged by formatted replacement.

See the [search API](https://inkkit.cyzr.me/reference/editor#searchmatches) and [host controls guide](https://inkkit.cyzr.me/guides/controls#build-your-own-find) for range lifetime and integration details. App-owned toolbars and window behavior remain separate from the editor.
