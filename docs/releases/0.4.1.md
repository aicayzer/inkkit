# Inkkit 0.4.1

Formatting or editing part of a paragraph keeps character references and backslash escapes elsewhere in that paragraph as authored. For example, making `words` bold in `Keep &amp; these words here` now saves `Keep &amp; these **words** here`, without respelling the untouched `&amp;`.

This applies when adding or removing formatting, including underline, superscript and subscript, and when typing beside existing inline formatting. Editing one character of a reference that represents multiple characters keeps all of its readable text. Exact save, reopen, undo and redo behavior remains covered by the preservation checks.

This is a compatible source-preservation fix for [#430](https://github.com/aicayzer/inkkit/issues/430). It adds no formats or public API. The separate WebKit caret-height and long-document source-typing investigations remain open; this release does not claim to fix them.

Hosts update the package, rebuild their offline page and regenerate their license notices. The unchanged `InkKitRTF` Swift package resolves from the same release tag.
