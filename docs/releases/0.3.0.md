# Inkkit 0.3.0

More reliable continuation-line typing and list paste, with small appearance improvements.

## Fixed

- Typing Markdown-looking markers at the start of a continuation line saves the literal text instead of refusing the edit. This includes headings, lists, quotes and code fences.
- Pasting HTML or Obsidian block comments into a tight list item preserves the complete content and its block structure, without changing authored list spacing.
- Dragging into the editor shows the drop position, including when re-entering at the same coordinates. Destroying the editor cancels the pending indicator timer.
- Focus styles reach code controls; reference definitions and wiki-link suggestions respect the configured fonts and sizes.

## Appearance

- Tables have 4px outer corners with square internal cell divisions. Set `--inkkit-table-radius: 0px` to keep square corners.
- Hosts can set unchecked checkbox borders with `--inkkit-checkbox-border-color` and the drop marker with `--inkkit-drop-indicator-color`.

## Compatibility

This release adds documented appearance controls. No existing public methods or options are removed. Document contents and supported formats are unchanged. Apps must adopt the published package separately.
