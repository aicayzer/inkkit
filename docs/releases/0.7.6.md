# Inkkit 0.7.6

This patch release fixes deleting the text of a line inside a paragraph, records more keyboard input in diagnostics, and lets a host turn the slash menu on and off without remounting the editor.

**Deleting all the text of a line deletes its line ending.** Emptying the last or a middle line of a paragraph with soft line endings was refused with `preservation`, because Markdown can't represent an empty line inside a paragraph. Emptying the line before a hard break written as trailing spaces or `<br>` was refused the same way. The line ending now goes in the same step, for soft and hard breaks alike, and one Undo restores both. A hard break at the end of a paragraph is still kept while you type after it.

**Diagnostics record keys the editor handles itself.** Backspace, Delete, Undo and Redo handled by Inkkit's own key bindings fire no `beforeinput` event, so diagnostics missed them. They are now recorded as `input` events with the new phase `handled`. The key itself is never recorded.

**`setSlashMenuEnabled(enabled)` turns the slash menu on or off after mount.** Turning it off closes an open slash menu. The other slash menu options passed at mount are kept.

See [the editor reference](https://inkkit.cyzr.me/reference/editor).

Hosts update the package and rebuild their offline page. The unchanged `InkKitRTF` Swift package resolves from the same release tag.
