# Inkkit 0.7.9

This patch release adds tokens for the look of the file placeholder that 0.7.8 introduced. It is additive: each token defaults to the look the placeholder had in 0.7.8, so a host that sets none of them sees no change, and no existing field or token changes meaning.

**A host can restyle a file placeholder with `--inkkit-file-placeholder-*` tokens.** Set them on the editor root or an ancestor:

- The box: `-background`, `-radius`, `-min-height`, `-padding` and `-gap`.
- The line: `-color`, the label's color, and `-font-size`.
- The symbol: `-symbol-color` and `-symbol-size`.
- The button: `-button-background`, `-button-hover-background`, `-button-border-color`, `-button-hover-border-color`, `-button-color`, `-button-font-size`, `-button-font-weight`, `-button-height`, `-button-padding-inline` and `-button-radius`.

The box still takes the width of its content. A minimum height keeps the symbol, label and button centered in the box, and the outline of a selected placeholder follows the radius token. The button's focus ring, keyboard use and accessible name don't change.

See [the appearance reference](https://inkkit.cyzr.me/reference/appearance#file-placeholder-tokens) and [placeholder options](https://inkkit.cyzr.me/reference/adapters#placeholder-options).

Hosts update the package and rebuild their offline page. The unchanged `InkKitRTF` Swift package resolves from the same release tag.
