# Inkkit 0.1.7

Editing and source-preservation fixes from the reduced first wave.

- Cut and Paste within the same editor and loaded document preserves private comments. External clipboard output excludes them (#217).
- Replacing a document leaves a safe insertion point after a final divider or atomic block (#219).
- Deletion immediately after Find and arrow movement follows the current caret (#166).
- Source edits discard obsolete Redo history while retaining valid Undo history (#128).
- Dragged image output excludes private references and display URLs while retaining internal movement (#152).
- Plain-text paste preserves actual line breaks and blank lines across insertion routes, including table cells (#73).
- Deleting introductory list text and manually wrapped paragraphs no longer becomes stuck; nested content and surrounding source remain intact (#129, #234).
- Spaces beside soft line breaks survive editing, saving and reopening. Encoded spaces remain spaces, without changing a soft break into a hard break (#145).
- File cards show the message supplied by an error presentation (#316).

Compatibility review: this release adds no public API and requires no host migration. The required complete-token `raw` contract for links and embeds (#308/#320), link-end typing (#133), paste-caret work (#221), selection appearance (#74) and drop-position feedback (#155) remain deferred. Apps must adopt this package version separately to receive these fixes.

Verification includes regression tests, the full Chromium and WebKit suites, and selected packed-candidate WKWebView checks on Atlas. The highlighting correctness test now uses a deterministic clock; separate coverage retains the production time-budget behavior (#318).
