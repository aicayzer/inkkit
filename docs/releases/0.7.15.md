# Inkkit 0.7.15

This patch release adds editor options that a host's settings can set: three typing options, two display options and a default paste route. Each is off or keeps today's behavior unless the host sets it, except list continuation in source mode, which is now on by default. See [the options reference](https://inkkit.cyzr.me/reference/options).

## Typing

New fields in `TextInputPreferences`, set through `textInput` at mount or `setTextInputPreferences`. That call replaces the whole set, so send every preference at once.

- **`pairBrackets`** (default `false`): typing `(`, `[`, `{`, `"` or `'` also inserts its closer, in formatted, source and TXT modes. Typing the closer steps over it, Backspace in an empty pair removes both, and a selection on one line is wrapped. A sequence you type with every closer saves the same bytes as with pairing off. A pair stays tracked through your own typing and corrections inside it. Paste, undo, a replacement or a host call ends the tracking, and the brackets then behave as ordinary characters.
- **`continueLists`** (default `true`): Return in a list item starts the next item. This is new in source mode, where it keeps the marker, numbering, task box, indentation and blockquote prefix, and never applies in code, HTML, front matter or comments. Set it to `false` to turn continuation off in both modes. In formatted mode, Return then adds a paragraph in the same item, or a line break in an RTF list item.
- **`indent`** (`'tab'` or `'spaces'`, default `'tab'`) and **`indentWidth`** (1 to 8, default 4): what Tab inserts in source and TXT modes. Tab and Shift-Tab indent and outdent a selection of lines, and a list item line nests as a whole. Shift-Tab no longer inserts a tab. In a browser's source surface, Tab keeps moving focus until the host sets either field; once set, Escape then Tab leaves the editor.

## Display

A new `display` group of `DisplayPreferences` in `EditorOptions`, and `setDisplayPreferences` to change it later. Both fields are presentation only: the document, revision, history, dirty state, copy and print output don't change.

- **`foldHeadings`** (default `false`): a control beside each top-level heading folds the section after it. Folded text can't be changed or deleted unseen. A selection that reaches into a fold opens it, a key next to a fold opens it instead of deleting, and an edit to text that hasn't been shown yet is refused with the new error code `hidden-text`. New labels: `foldHeading` and `unfoldHeading`.
- **`codeLineNumbers`** (default `false`): a number beside each line of a code block, kept beside wrapped lines. The numbers are never selected, copied, printed or read by assistive technology. New token: `--inkkit-code-line-number`.

## Paste

- **`textInput.paste`** (`'formatted'` or `'plainText'`, default `'formatted'`): with `'plainText'`, every paste inserts the clipboard's plain text literally, as `pasteAsPlainText` does, in every mode and format. A paste with no plain text imports only its images.

## Other changes

- Painting a whole-document selection no longer walks the document from the start for each painted range.

An unedited document still saves byte for byte. Hosts update the package and rebuild their offline page. The unchanged `InkKitRTF` Swift package resolves from the same release tag.
