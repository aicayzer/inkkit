# Inkkit 0.7.5

This patch release adds tokens for the look of wiki links and tables. A host that sets none of them sees no change. It adds no API.

**More of a wiki link's look is a token.** `--inkkit-wiki-link-underline-style` sets the style of a found link's line, such as `dotted`, and `--inkkit-wiki-link-cursor` sets the cursor over a link. `--inkkit-wiki-link-missing-underline-style` and `--inkkit-wiki-link-missing-underline-color` set a missing link's line, for example a lighter one. In forced colors a missing link is still drawn dashed and a found link solid, so the two differ by their line.

**More of a table's look is a token.** `--inkkit-table-spacing-before` adds space above a table. `--inkkit-table-header-background`, `--inkkit-table-header-font-weight` and `--inkkit-table-header-color` set the header cells, and `--inkkit-table-grip-color` sets the dots on the column and row grips at rest.

See [the appearance reference](https://inkkit.cyzr.me/reference/appearance).

Hosts update the package and rebuild their offline page. The unchanged `InkKitRTF` Swift package resolves from the same release tag.
