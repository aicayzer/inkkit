# Inkkit 0.7.14

This patch release fixes three faults in editing around links. Each one changed what a document saves or what Undo gives back. It changes no public API.

**Shortening a bare URL before a line break updates its link.** Deleting the final `h` of `https://example.com/path` before a line break now saves `https://example.com/pat`, linked to `https://example.com/pat`. Before, the link kept its old target and was saved as `[https://example.com/pat](https://example.com/path)`. Before a hard break, the URL is saved in angle brackets, such as `<https://example.com/pat>`, so the break can't run into it.

**A backslash in a bare address is read as part of it, as GFM reads it.**

- Typing an address with a backslash in it, such as `https://example.com/a\b`, links it. Before, the edit was refused with `preservation` and the keystroke did nothing.
- A backslash typed at the end of a bare address joins the address, as a letter does, and the address stays bare.
- Editing an address that ends in a backslash before a line ending keeps its link in step with its text.

**Formatting that covers a link and the text after it stays one run.** Typing `x` after `and` in `See _https://example.com and_ more` now saves `See _https://example.com andx_ more`. Before, it saved `See *https://example.com* *andx* more`. This holds for every emphasis, strong and strikethrough delimiter, for bare, angle and bracket links, and for formatting nested in another layer, such as `**_https://example.com_ and**`. Spaces at the edge of formatting are still written outside it.

**Undo restores the document after typing beside a URL and a character reference.** Typing `x` after `See https://example.com&amp;` and then pressing Undo now restores the loaded bytes, the unchanged state and the link. Before, Undo saved `https://example.com&` and linked the `&` into the address.

An unedited document still saves byte for byte, and blocks an edit doesn't reach keep their bytes. See [Markdown support](https://inkkit.cyzr.me/concepts/markdown).

Hosts update the package and rebuild their offline page. The unchanged `InkKitRTF` Swift package resolves from the same release tag.
