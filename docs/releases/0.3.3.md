# Inkkit 0.3.3

Keyboard access for tasks, links and images, clearer default colors, and license notices for offline host pages.

## Added

- Task markers expose a checkbox with its checked state and accessible name. Focus a marker and press Space or Enter to toggle it. Hosts can use `format('toggleTask')`, its command availability, or a configured `toggleTask` shortcut at the caret. Read-only and composition guards still apply; the saved source changes only the task marker.
- The configurable `openLink` shortcut opens the Markdown link at the caret or a selected wiki link through the existing host callbacks. It works in read-only formatted text and retains the authored wiki reference. There is no default binding.
- Image resize handles are keyboard-focusable and show a focus ring. Arrow keys change the width by 10 pixels, Shift+arrow by 1 pixel, and Home/End choose the supported bounds. Resize keeps the existing source preservation and undo behavior.
- `imageResize` and `taskCheckbox` labels let hosts name the new controls. Existing hosts can keep the English defaults.

## Fixed

- Read-only formatted text can receive keyboard focus, including the link-opening shortcut, without enabling editing.
- Keyboard traversal skips sandboxed PDF previews, avoiding WebKit's focus trap. The Open button remains the keyboard path to the document; the sandbox is unchanged.
- Default link and footnote colors meet text contrast in light and dark appearances. Task borders meet control contrast, and checked tasks retain a visible tick in forced colors. Host color tokens still override the defaults.
- Task controls update around changed content instead of scanning every unchanged block during ordinary typing.

## Bundled-page notices

The package generates a full-entry reference notice for its tested Mermaid dependency tree as well as notices for its prebundled code. The [web-view guide](https://inkkit.cyzr.me/guides/web-view#carry-the-license-notices) shows hosts how to generate notices from their own lockfile and carry them with the offline page. Notices do not by themselves establish compliance with every license term.

## Compatibility and limits

The task command, shortcut name and labels are additive. The maintainer chose 0.3.3 for this compatible iteration. Existing keymaps keep their behavior until the host binds a new command.

The native source-typing latency target in [issue #206](https://github.com/aicayzer/inkkit/issues/206) remains open. Very long single lists, diagram-heavy performance, internal restructuring and playground redesign are separate work. Apps adopt this release separately.
