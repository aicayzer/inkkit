# Inkkit 0.7.16

This patch release makes links easier to use. An editor that can be edited still places the caret on a plain click and opens a link on a Mod-click, and now it shows that. A host can also show its own menu on a link. Nothing changes for a host that sets none of the new options. See [the options reference](https://inkkit.cyzr.me/reference/options).

## Seeing how a link opens

- **Pointer and look:** while Mod is held over a link, it shows a hand pointer and a ready-to-open look. In an editor that can't be edited, a hover alone shows them.
- **Hint:** after the pointer rests on a link in an editor that can be edited, a short hint says how to open it. It is drawn outside the document, so it never reaches the text, a copy or an edit. New label: `linkOpenHint` (`⌘-click to open` on Apple platforms, `Ctrl-click to open` elsewhere). An empty text draws no hint.
- **Tokens:** `--inkkit-link-color`, `--inkkit-link-radius`, `--inkkit-link-hover-color`, `--inkkit-link-hover-underline`, `--inkkit-link-hover-background`, `--inkkit-link-open-cursor`, `--inkkit-link-open-color`, `--inkkit-link-open-underline`, `--inkkit-link-open-background`, `--inkkit-link-hint-background`, `--inkkit-link-hint-color` and `--inkkit-link-hint-radius`. Markdown links and wiki links share them. The defaults keep today's look.

## Opening links

- **Read-only editors:** a plain click opens a Markdown link through `events.openLink` or a wiki link through `WikiLinkAdapter.open`, unless it is a double click or ends a text selection. Mod-click, Enter and Space work as before.

## Link menu

- **`events.linkMenu(link, point)`:** called when the person asks for the context menu on a Markdown link or a wiki link. Inkkit selects the link, cancels the web view's menu and passes a new `LinkMenuTarget` (`kind`, `text`, `range`, and `href` with `openable` for a Markdown link or `reference` for a wiki link) and a `ClientPoint`. Without the handler, the web view's menu shows as before.
- **Edit and remove:** `format('link', { destination })` and `format('link')` edit and remove the selected Markdown link. `paste({ text: '', markdown })` and `pasteAsPlainText(text)` rewrite and remove the selected wiki link. See [Show a link menu](https://inkkit.cyzr.me/guides/controls#show-a-link-menu).

## Documentation

- The `openLink` shortcut example `Mod-O` was Command-Shift-O. The shortcuts reference now explains the key notation and uses `Mod-Shift-Enter`.

An unedited document still saves byte for byte. Hosts update the package and rebuild their offline page. The unchanged `InkKitRTF` Swift package resolves from the same release tag.
