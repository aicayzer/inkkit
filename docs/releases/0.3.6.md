# Inkkit 0.3.6

Editing a long bullet or task list validates the changed item runs instead of reparsing the whole list. Enter, Backspace and subsequent typing retain authored Markdown, including list markers, emphasis spelling and line endings. Task checkbox labels refresh only for changed items. Unsafe contexts and ordered-list renumbering retain the complete validation path.

This addresses [#259](https://github.com/aicayzer/inkkit/issues/259). Dependency versions and the diagram renderer are unchanged. The existing ProseMirror patch now searches sorted decoration offsets without scanning preceding list items. Hosts update the package and rebuild their offline page as usual.

The independently merged [#421](https://github.com/aicayzer/inkkit/issues/421) adds the optional `formats` mount option and `editor.formats`. Hosts can choose which existing formats they offer; Markdown and TXT remain the defaults and retain exact saving. This release adds no new document format.

The independently merged [#431](https://github.com/aicayzer/inkkit/pull/431) adds underline, superscript and subscript commands, shortcuts and styling tokens. Balanced lowercase `<u>`, `<sup>` and `<sub>` pairs without attributes render as marks and retain their saved bytes. Other tag forms retain their existing literal behavior. The change also fixes editing paragraphs filled by a mark or link that contains an HTML line break.

The remaining native source-input investigation in [#206](https://github.com/aicayzer/inkkit/issues/206) stays open: correctness passes, but the recorded WKWebView latency target remains unmet. This release does not claim a source-typing speed improvement. Measurement commands and results are recorded in the [performance guide](https://github.com/aicayzer/inkkit/blob/main/docs/maintainers/performance.md).
