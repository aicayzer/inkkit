# Inkkit 0.6.0

Inkkit includes three optional CSS themes: **Standard**, **Calm** and **Essential**. Standard keeps the familiar colours with lighter code surfaces, Calm uses a softer palette, and Essential uses neutral greys. Each supports light and dark appearances with system typography at 15px.

Import the base stylesheet and a preset, then set its name on the editor host:

```ts
import '@aicayzer/inkkit/style.css'
import '@aicayzer/inkkit/themes/standard.css'

root.dataset.inkkitTheme = 'standard'
```

Use `calm` or `essential` with the corresponding stylesheet for the other presets. Switching the attribute changes appearance without reloading the document or clearing undo history. Existing editors that do not select a preset keep their current appearance.

Standard and Calm have 8px table and code-block corners; Essential has 4px corners. All three use a neutral quote rule with rounded ends. New public CSS tokens control the editor background, code-block radius and quote-rule colour, width and radius. These are additive styling controls, so this release raises the minor version. See the [appearance guide](https://inkkit.cyzr.me/guides/appearance) for imports and customisation, and the [token reference](https://inkkit.cyzr.me/reference/appearance) for defaults.

The documentation playground lets you compare the presets and light and dark appearances while editing the same document. A full theme designer and additional font choices remain separate work.

This release does not claim to resolve the separate intermittent editing-refusal, native caret or predictive-text investigations. Hosts adopt the published package separately, rebuild their offline editor page and regenerate their notices.
