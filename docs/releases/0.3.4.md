# Inkkit 0.3.4

A maintenance checkpoint for exact saving, editing reliability and simpler internals. The public API, CSS contract and supported formats are unchanged.

## Fixed

- Readable copy excludes private comments correctly when a document starts with byte-order marks. Explicit Markdown export and saved source retain the authored bytes.
- Backspace and Delete in source and TXT modes remove a complete grapheme, including joined emoji, flags and combining marks, even when the caret is inside it. Explicit selections keep their existing behavior.
- Spreadsheet import classifies parsed elements and attributes instead of matching HTML text. Metadata-like cell text remains ordinary content, and unsupported tables retain the safe fallback.
- Preservation falls back only for recognized failures. Unexpected defects remain diagnosable, and failed operations retain the document, selection, revision and history.

## Maintenance

- Split editor assembly, commands, source history, clipboard output, geometry and search into focused modules. Split preservation parsing, alignment, authored syntax retention, incremental validation and reconstruction while retaining the coordinator and its validation rules.
- Share small helpers without changing their callers' BOM, text, image MIME or byte-encoding behavior. Remove proven dead internal declarations.
- Replace elapsed test waits with explicit history boundaries and observable completion. Keep deterministic preservation seeds and independent whole-document comparisons.
- Replace the slash-menu snapshot with independent Markdown expectations for all 312 cases, retaining exact saves, reopening, undo and redo. Merge repeated read-only browser setup and remove only proven duplicate refusal checks.
- Build the shared browser fixture before CI runs its isolated test contexts. Controlled comparisons reduce fixture workload time in both engines while retaining failure diagnostics and the existing checks.
- Strengthen API reference checks so each declaration or member needs its own substantive description. Consolidate native scenarios and preserve fixture input bytes before they reach the editor.

## Compatibility and limits

Hosts can keep their current imports, adapters, options, events, labels and color tokens. No format or renderer is added, and Mermaid remains the diagram renderer. Host adoption is separate from package publication.

The Pele trial, RTF and MDX work, long-document performance targets and other deferred issues remain separate work.
