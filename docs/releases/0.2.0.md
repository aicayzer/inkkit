# Inkkit 0.2.0

Image-import cancellation, paste reliability and pointer fixes.

## Added

- Hosts can call `cancelPendingImports(expectedGeneration?)` to cancel a stalled image paste or drop without changing editability. Cancellation immediately releases saving and discards the entire pending paste.
- Image import adapters receive `ImageImportContext.signal`, aborted on cancellation, document replacement, read-only transitions and destruction. Adapters should stop work and clean up unused bytes when aborted; late results cannot change the document.

## Fixed

- Ticking a checklist item preserves the writing selection and does not steal focus from another input.
- Block-boundary selections show only their gap indicator, without a second native text caret.
- Table drag handles show the grab pointer.

- HTML pastes retain their surrounding text and an image placeholder when an adapter rejects with `image-unavailable`.
- Tab-indented plain text no longer becomes a table solely because it contains a tab. Outside a table, plain TSV requires multiple rectangular rows and a nonblank first-column value; HTML without a table takes precedence over TSV fallback. Existing table filling remains supported.
- Typing after pasted terminal comments or folded callouts goes after the pasted blocks. Paste placement respects callouts folded or opened by the reader.

## Compatibility

This batch adds public API and intentionally changes TSV inference. Existing image adapters that accept DocumentContext can continue to do so; host test doubles constructing ImageImportContext must include a signal. Apps must adopt this release separately. Link-boundary typing, authored wiki-link `raw`, selection tokens, drop indication and table-corner polish remain separate work.
