Inkkit is a Markdown editor that you mount in a web page or in an app's web view. People edit formatted text. Your app loads and saves plain Markdown, and anything they didn't edit is saved exactly as it was written.

Inkkit is built on [Milkdown](https://milkdown.dev) and [ProseMirror](https://prosemirror.net) and is published to npm as `@aicayzer/inkkit`.

## How it works

Most formatted Markdown editors rebuild the whole file when they save, so list markers, spacing and escaping change in places nobody touched. Inkkit keeps the text it loaded. An unedited document saves byte for byte. An edit rewrites only the blocks it changed, and Inkkit reads the result back before keeping it.

A refused edit changes nothing and reports a `preservation` error. See [Preservation](/concepts/preservation) for the exact guarantees.

## What Inkkit does and what your app does

    - Code highlighting and Mermaid diagram previews, offline
    - Paste from web pages and spreadsheets, kept to Markdown that reads back the same

    - Writing the system clipboard, printing, and opening links and files
    - Keyboard shortcuts, localized text and appearance, through options and tokens

## When it helps

- Your app stores Markdown files, and people expect them to stay as they wrote them, including files they also edit elsewhere.
- You want formatted editing without hiding the source. Your app can switch to source mode at any time, and both modes share one undo history.
- You build your own interface around the editor. Inkkit runs offline from one bundled page and makes no network requests, which suits native apps that host a web view.

## Limitations

- **One editor, one document.** There is no real-time collaboration.
- **No application interface.** Inkkit draws the document and its inline controls, such as table and image controls, but not a toolbar or menus. It binds no formatting shortcuts until you supply them.
- **A fixed feature set.** You configure Inkkit through options, adapters, labels and tokens. It doesn't load your own ProseMirror plugins or node types.
- **No framework components.** Inkkit mounts into a DOM element, so you can use it from React, Vue or any other framework, but you write the small wrapper yourself. The package is ESM only.
- **Markdown and plain text only.** Inkkit edits Markdown and TXT documents. Syntax it doesn't support, such as math, stays as editable literal text. Right-to-left text isn't supported yet ([#165](https://github.com/aicayzer/inkkit/issues/165)).
- **Tested engines.** CI tests Chromium and WebKit. Firefox meets the API requirements but isn't tested. Diagram previews make up most of the page size; an entry without them is available. See [Compatibility](/compatibility).
- **Pre-1.0.** The API can change between minor versions. Pin an exact version and read the [release notes](https://github.com/aicayzer/inkkit/releases).

Inkkit is used in [Memos](https://github.com/aicayzer/memos) and [PadPad](https://github.com/aicayzer/padpad), two Mac apps whose source shows complete web view hosts.
